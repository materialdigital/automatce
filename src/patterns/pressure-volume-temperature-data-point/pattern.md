# Pattern: Pressure Volume Temperature Data Point

## Purpose

Represent one pressure-volume-temperature tuple for a material.

## Description

A pVT data collection links to data points with `AUTOMATCE_0009008`. Each data point must link to one pressure datum, one temperature datum, and one specific volume datum. Each datum should carry one scalar value and, when available, one unit.
