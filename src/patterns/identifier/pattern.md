# Pattern: Identifier

## Purpose

Represent identifiers for manufacturers, materials, batches, parts, vehicles, logistics transfers, and Catena-X assets.

## Description

Identifier classes are modeled under `IAO_0020000` or a more specific imported PMD/LOG identifier. The identifier value remains instance data. Local AutoMatCE classes are used only when the identifier is narrower than the imported PMD or LOG class.
