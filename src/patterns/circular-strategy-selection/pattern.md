# Pattern: Circular Strategy Selection

## Purpose

Represent the selected circular economy strategy for a product, component, material, or recycling batch.

## Description

The information record is an AutoMatCE circular economy information entity. It points to exactly one selected R-strategy with `automatce:AUTOMATCE_0009006`. Strategy values remain directive information entities, not free text.
