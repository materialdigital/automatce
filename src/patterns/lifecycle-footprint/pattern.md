# Pattern: Lifecycle Footprint

## Purpose

Represent product carbon footprint values for lifecycle stages and circular economy scenarios.

## Description

Use AutoMatCE product carbon footprint subclasses for scenario-specific footprints. Store the numeric value with `OBI_0001937`, the unit with `IAO_0000039`, and the subject or lifecycle context with `IAO_0000136`.
