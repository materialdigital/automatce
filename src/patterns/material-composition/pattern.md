# Pattern: Material Composition

## Purpose

Represent the material constitution of a product, component, material, or recycling batch.

## Description

The carrier is linked to one PMD `composition` record with `automatce:AUTOMATCE_0009002`. Material proportions, constituents, and measurement values remain instance data. Use PMD Core material and proportion classes where available; create an AutoMatCE class only for an application-specific material concept.
