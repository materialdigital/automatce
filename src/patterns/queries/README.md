# AutoMatCE competency queries

These SPARQL queries show the intended graph shape for common exchange records.
They are written against the AutoMatCE release graph and example data that uses
the pattern object properties.

- `material-composition.rq`: components, products, materials, or batches linked
  to material composition records.
- `process-input-output.rq`: planned processes with inputs, outputs,
  participants, and realized plan specifications.
- `circular-strategy-footprint.rq`: circular economy strategy selection with
  scenario footprint values.
- `recycling-batch-transfer.rq`: recycling batches and transfer actors.
- `pvt-data-point.rq`: pressure-volume-temperature tuple values.
- `dismantling-condition.rq`: dismantling records with condition and damage
  information.
