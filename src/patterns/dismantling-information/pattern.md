# Pattern: Dismantling Information

## Purpose

Represent dismantling instructions, dismantlability, tools, and average dismantling time for a component.

## Description

Dismantling instructions are plan specifications. They should be about the component or assembly they describe. Quantified dismantling time remains a separate temporal interval or value specification, and dismantlability is represented as a disposition.
